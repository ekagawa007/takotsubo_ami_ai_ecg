- APIキー、アクセストークン、パスワード、秘密鍵の典型的な記載パターンは検出しなかった。
- 公開対象に個人のホームディレクトリパスや既知の個人端末・ユーザー名の残存は検出しなかった。一般化したパス例と、著者が公開を希望した著作権者名は保持している。

- 研究コードに明示的なHTTP/SMTP/FTPアップロードや不審なshell/eval/exec処理は見つからなかった。モデル実行や依存パッケージのインストールは行っていない。

## 公開・実行時に維持する条件

1. `.cache/`、私用原本、更新用スクリプトの親フォルダー、患者画像、参加者記録、実行時出力は公開しない。ブラウザーの手動アップロードでは `.gitignore` による除外に頼らない。
2. 推論結果には入力パスが記録され、可視化には元の心電図が含まれることがある。読影試験スクリプトは参加者情報を保存する。生成されたデータは今回の公開対象に含めない。
3. 既存コードは `torch.load` を使用する。信頼できないcheckpointは読み込まない。重みは今回同梱しておらず、配布前の別途確認が必要である。
4. pipによる依存関係導入、モデル・metric取得、Google Driveのマウント等は、実行時に外部通信を行う。依存バージョンや実行環境の検証は未完了である。
5. human-study管理プログラムは対話的実行を想定しており、公開Webサービスとしての安全性や同時書込みは検証していない。スケジュールhelperは呼出時に翌日まで待機する場合がある。

本確認は提供されたファイルの静的検査であり、将来の追加ファイル、依存ライブラリ、実行時挙動、学習済み重み、データセットの安全性を保証するものではない。ローカルにGit履歴は存在せず、公開後のGitHub上の内容も未確認である。
