# v0.2.0 release notes

Updated 2026-10-22 (JST); README documentation version `0.1.12`.

Release version `v0.2.0` adds separately packaged inference weights and their download workflow. Check the [release page](https://github.com/ekagawa007/takotsubo_ami_ai_ecg/releases/tag/v0.2.0) for the tag and available assets.

## Changes

- A separate inference-weight archive for the selected ViT, ConvNeXtV2 and MLP-Mixer models, with checksums and required configuration.
- `python tools/download_weights.py --output-dir weights` for the published assets.
- A Colab Release-download default, retaining an existing local/Drive weight option and live progress display.
- A [model card](../../MODEL_CARD.md), [separate weight terms](../../WEIGHTS_LICENSE.md) and [upstream notices](../../THIRD_PARTY_NOTICES.md).

Code package version is `0.2.0`. The selected tensors, paper TTA defaults, class order and equal raw-logit ensemble remain those documented for the preceding inference implementation. This packaging change does not claim new training or new clinical performance.

## Usage

From the matching source checkout, with a suitable Python/PyTorch environment:

```bash
python -m pip install -r requirements-inference.txt
python tools/download_weights.py --output-dir weights
python examples/predict_ensemble.py --image data/example_ecg.png --weights-dir weights --output outputs/prediction.json
```

The example image path must be replaced with a permitted prepared 480 x 480 image. If the weight asset is unavailable, the downloader reports a download failure; existing verified local weights can still be supplied. See [inference instructions](../inference.md).
