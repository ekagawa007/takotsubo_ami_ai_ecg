# v0.3.1: patched filelock dependency and verified inference

The inference requirements now explicitly install `filelock==4.2.1`, so updating an existing inference environment replaces the affected transitive dependency. CLI prediction metadata and Colab run records include its version. The patch addresses upstream advisories [GHSA-v4x8-3wr5-3wq8](https://github.com/tox-dev/filelock/security/advisories/GHSA-v4x8-3wr5-3wq8), [GHSA-9vhv-jxww-xfm5](https://github.com/tox-dev/filelock/security/advisories/GHSA-9vhv-jxww-xfm5) and [GHSA-567q-5qvw-pf92](https://github.com/tox-dev/filelock/security/advisories/GHSA-567q-5qvw-pf92). Their documented attack scenarios require local filesystem access.

Model computation, selected checkpoints, paper TTA settings, raw-logit aggregation and Grad-CAM calculations are unchanged. Install `requirements-inference.txt` in a dedicated inference environment; replacing source files alone does not upgrade installed dependencies. Historical training requirements are retained separately.

## Validation

- Windows CPU: 119 tests, 116 passed and three hardlink-permission skips; generated-image paper-TTA predictions and both Grad-CAM maps were exactly unchanged across the filelock substitution.
- WSL/RTX 5090 on 2026-10-28: 119 tests, 117 passed and two Windows-only skips. With Python 3.12.12, CUDA float32, one generated 480 x 480 image, paper TTA, batch 1 and zero workers, all predictions and both finite maps were exactly unchanged. The original environment was preserved.
- Colab/A100 on 2026-10-28: a fresh candidate inference environment with Python 3.13.16 and filelock 4.2.1 completed paper-TTA prediction and Grad-CAM. All 112 candidate source hashes, selected-weight/configuration hashes, prediction/run linkage and nine saved files were verified; map rendering and raw-logit aggregation were independently recalculated. Batch size was 1 with four workers.
- Twenty-five local notebook integration checks passed. These use mocked setup/Colab/GPU operations and are separate from the live candidate Colab run.

The final source differs from the tested candidate only in documentation, notebook Markdown and citation metadata. Final public-tag Colab source acquisition is a separate post-publication check. The candidate Colab run did not include a paired Grad-CAM-off comparison. These synthetic software checks do not establish clinical performance or historical stochastic-TTA/reader-study map equivalence. See [implementation status](../implementation_status.md) for conditions and limits.
