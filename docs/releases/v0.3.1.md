# v0.3.1: patched filelock dependency and verified inference

Updated 2026-10-28 (JST); documentation revision 0.1.22. The post-publication verification below supplements the original release-preparation evidence.

The inference requirements now explicitly install `filelock==4.2.1`, so updating an existing inference environment replaces the affected transitive dependency. CLI prediction metadata and Colab run records include its version. The patch addresses upstream advisories [GHSA-v4x8-3wr5-3wq8](https://github.com/tox-dev/filelock/security/advisories/GHSA-v4x8-3wr5-3wq8), [GHSA-9vhv-jxww-xfm5](https://github.com/tox-dev/filelock/security/advisories/GHSA-9vhv-jxww-xfm5) and [GHSA-567q-5qvw-pf92](https://github.com/tox-dev/filelock/security/advisories/GHSA-567q-5qvw-pf92). Their documented attack scenarios require local filesystem access.

Model computation, selected checkpoints, paper TTA settings, raw-logit aggregation and Grad-CAM calculations are unchanged. Install `requirements-inference.txt` in a dedicated inference environment; replacing source files alone does not upgrade installed dependencies. Historical training requirements are retained separately.

## Validation

- Windows CPU: 119 tests, 116 passed and three hardlink-permission skips; generated-image paper-TTA predictions and both Grad-CAM maps were exactly unchanged across the filelock substitution.
- WSL/RTX 5090 on 2026-10-28: 119 tests, 117 passed and two Windows-only skips. With Python 3.12.12, CUDA float32, one generated 480 x 480 image, paper TTA, batch 1 and zero workers, all predictions and both finite maps were exactly unchanged. The original environment was preserved.
- Colab/A100 on 2026-10-28: a fresh candidate inference environment with Python 3.13.16 and filelock 4.2.1 completed paper-TTA prediction and Grad-CAM. All 112 candidate source hashes, selected-weight/configuration hashes, prediction/run linkage and nine saved files were verified; map rendering and raw-logit aggregation were independently recalculated. Batch size was 1 with four workers.
- Twenty-five local notebook integration checks passed. These use mocked setup/Colab/GPU operations and are separate from the live candidate Colab run.

The final source differs from the tested candidate only in documentation, notebook Markdown and citation metadata. At release preparation, final public-tag Colab source acquisition was a separate post-publication check; the completed follow-up is recorded below. The candidate Colab run did not include a paired Grad-CAM-off comparison. These synthetic software checks do not establish clinical performance or historical stochastic-TTA/reader-study map equivalence. See [implementation status](../implementation_status.md) for conditions and limits.

## Post-publication verification: 2026-10-28

On 2026-10-28, the public v0.3.1 tag completed the Colab workflow at commit `aa1c8f4596b63bed39c53e390e67318d1836b7f7`, using an A100-SXM4-40GB, Python 3.13.16, filelock 4.2.1 and CUDA float32. The input was one generated 480 x 480 RGB image; prediction used paper TTA (ViT 24/magnitude 1, ConvNeXtV2 one unchanged view, MLP-Mixer 32/magnitude 3), equal-weight raw-logit aggregation, batch size 1, four workers and seed 1234.

All 20 recorded inference-source hashes, the three official checkpoint hashes and ViT configuration hash matched. Input pixels, prediction/run linkage and all nine ZIP members (two JSONs and seven visualization artifacts) were verified; softmax and raw-logit aggregation were independently recalculated. All model/ensemble logits and probabilities exactly matched the candidate Colab run under matching input and settings. Both maps were finite, nonconstant float32 480 x 480 arrays, and their heatmaps/overlays matched independently recalculated rendering. The ViT map differed from the candidate by at most `2.384185791015625e-7`; ConvNeXtV2 map and PNG bytes were identical.

This completes the public-tag Colab workflow check. This public Colab run did not include a paired Grad-CAM-off comparison. These synthetic software checks do not establish clinical performance or historical stochastic-TTA/reader-study map equivalence. This documentation update leaves release tags, inference code, dependencies, weights and existing DOI identities unchanged.
