# v0.4.0: image preparation and Colab input controls

Release date: 2026-10-29 (JST). Original documentation revision: 0.1.24. Follow-up updated 2026-10-29 (JST), documentation revision 0.1.27.

Images that are not already 480 x 480 can now be prepared explicitly in both CLI and Colab: `square-resize` resizes a square, `center-crop` takes the centered short-edge square, and `pad` centers the image on a white long-edge square. Each operation produces a 480 x 480 input shared by prediction, preview and Grad-CAM. The default remains `strict480`; no resizing is selected automatically.

Colab now offers generated images, one computer upload or a Google Drive image, with a prepared-image preview. Automatic device selection warns before CPU fallback and uses the matching CPU or CUDA environment. TTA presets are Paper defaults, No TTA and Custom; CPU fallback does not silently reduce TTA. After changing a form, run that settings cell and confirm the printed effective values before inference. Grad-CAM remains enabled by default for ViT/ConvNeXtV2, with in-notebook display and one linked result ZIP.

The prediction calculation, default paper TTA, class order, equal raw-logit ensemble and selected v0.2.0 weights remain unchanged. No new weight download is required for a verified existing installation. Code remains MIT licensed; the separate model-weight terms, including the ViT noncommercial condition, continue to apply. The [v0.4.0 source archive](https://doi.org/10.5281/zenodo.23763944) was published on Zenodo on 2026-10-29. The earlier [v0.3.0 source DOI](https://doi.org/10.5281/zenodo.23666137) and the [v0.2.0 weight DOI](https://doi.org/10.5281/zenodo.23666262) continue to identify their original versions.

## Validation

- Local candidate suite: 172 tests, 169 passed, three unavailable-hardlink cases skipped, no failures/errors.
- Selected-weight CPU paper-TTA comparison on one generated 480 x 480 image: all three model/ensemble prediction values, both numerical Grad-CAM maps and prepared pixels exactly matched the saved baseline.
- Each new geometry policy: selected-weight ViT/no-TTA predictions, numerical Grad-CAM and pixels exactly matched an independently prepared image.
- Eight candidate Colab runs: A100 paper-TTA execution with generated input, uploaded square resizing, uploaded rectangle cropping/padding and a Drive image; CPU automatic fallback with paper TTA twice and No TTA once. The recorded 118 source hashes, official weight/configuration hashes, linked predictions and nine saved files per run were checked.

Candidate execution and public-tag acquisition are separate checks. The final public-tag workflow subsequently completed as described below. These results establish the described software workflows, not clinical performance, historical stochastic-TTA or reader-study visualization equivalence, or exhaustive coverage of all custom settings. See [implementation status](../implementation_status.md#v040-image-input-and-colab-controls) for conditions and limits.
