# v0.2.1 — input/output protection and tested inference dependencies

Prepared: 2026-10-23 (JST). Code version: 0.2.1. Documentation version: 0.1.14. Weight assets: v0.2.0.

Prediction saving reserves new files exclusively, protects input/model files by identity, and stages explicit replacements. CSV and its metadata sidecar are checked separately. A partial two-file save reports failure and retains uncertain files for inspection. The downloader likewise retains incomplete installations instead of deleting through a destination path that may have changed. Archive and member checksum verification is unchanged.

Image decoding is restricted to single-frame PNG, JPEG, BMP, TIFF and WebP in both the initial checks and worker reads. Animated, multipage and disguised unsupported files are rejected. Default preprocessing remains RGB 480 x 480; explicit resizing uses the complete image with bilinear interpolation.

Inference now specifies torch 2.13.0, torchvision 0.28.0, transformers 5.10.4, Pillow 13.0.0 and the other tested dependencies in `requirements-inference.txt`. A strict ViT adapter maps legacy parameter names to the Transformers 5 layout without changing tensor values. The historical training requirements, selected weights, normalization, class order, paper TTA settings and raw-logit ensemble are preserved.

The English Colab example uses a separate inference virtual environment, defaults to a generated example, and supports a permitted existing image with optional Drive mounting. It displays live progress and subprocess errors, creates unique output names and downloads the matching prediction/run records in one ZIP.

Validation on 2026-10-23:

- WSL/RTX 5090: 85 tests discovered, 83 passed and two Windows-only tests skipped. Ten private real ECGs matched frozen original-evaluator predictions within `atol=rtol=1e-5` under float32/no-TTA conditions. All models and the ensemble had zero class changes; maximum logit difference `7.034942627e-7`, maximum probability difference `1.352990612e-7`.
- Colab/A100: the tested pre-release workflow completed one synthetic-image run with the paper TTA settings and float32, including weight preparation, live progress and matching saved records. Source/weight identities and the raw-logit ensemble were checked independently.
- Final public notebook: format/syntax validation and 12 local checks passed; GitHub/network and inference subprocess behavior were simulated where a live service was unavailable. The final tag-based checkout is not claimed as a completed Colab run.
- Native Windows CPU: 83 of 85 tests passed; two hardlink cases were skipped due to account permissions. The separate dependency comparisons on ten real images without TTA and one synthetic image with paper TTA passed the same tolerance.

The final public notebook selects `v0.2.1` after that tag is published. Its GitHub checkout path remains a post-publication check; the tested pre-release workflow supplied the reviewed source as a verified archive. Historical paper-TTA numerical equivalence and clinical performance are not established by these checks. See [implementation status](../implementation_status.md).

The downloader continues to use the already published v0.2.0 weight archive. A new weight archive is unnecessary. Existing release tags are retained.
